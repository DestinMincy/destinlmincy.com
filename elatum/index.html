The Problem

Guests don't stop asking questions at 11 PM.

STR operators in the Smokies handle dozens of repeat questions every week — WiFi passwords, hot tub temps, check-out instructions, bear trash rules, Cades Cove hours. That's time you're not getting back, and a slow response to a guest text after hours is a 5-star review you're not going to get.

Airbnb penalizes slow response

Response time under 2 minutes protects your search ranking and Superhost status. Every unanswered message is a ranking event.

The same 20 questions, forever

WiFi, door code, check-out, hot tub, trash, directions. Hyper-repetitive work that consumes your evenings and weekends.

Generic AI doesn't know your backyard

ChatGPT can't tell a guest whether Cades Cove is vehicle-free on a Tuesday or when Elkmont fireflies are running. ELATUM can.

How It Works

A 7-node AI pipeline — from guest message to accurate response.

Every guest message — SMS or web chat — flows through a purpose-built agent pipeline powered by a specialized large language model. No hallucinations, no generic answers. Every response is grounded in your property documents and real local data.

01

Ingest

Guest message arrives via SMS (Twilio) or web chat (QR code). Metadata extracted and normalized.

02

Guest Lookup

Phone number or booking reference matched to active reservation in the database. Context — name, property, dates — loaded.

03

Intent Classification

ELATUM's AI classifies the message into one of eight intent categories: WiFi, check-out, damage report, amenity question, booking, local recommendation, payment, or escalation.

04

RAG Retrieval

Relevant documents retrieved from PostgreSQL + pgvector — your cabin manual, house rules, and hyper-local knowledge base — using semantic vector search.

05

Response Generation

A response is generated grounded in retrieved context — concise, warm, property-specific. No fabrication.

06

Action Execution

Based on intent: send SMS reply, generate Stripe payment link, create a maintenance ticket, or escalate to the owner with context pre-filled.

07

Audit Log

Every message, intent classification, and action logged to the host dashboard. Full conversation history available for review.

The Competitive Moat

Trained on knowledge no generic AI has.

The ELATUM knowledge base is built from real local data — not web scrapes from 2023. Every property gets a bespoke RAG corpus ingested from your own documents, plus a shared East TN layer that updates with the region.
